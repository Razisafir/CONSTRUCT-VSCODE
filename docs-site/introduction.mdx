# Introduction

Kovix is an AI-native development environment with autonomous coding agents built directly into the editor.

## Key Features

- **Autonomous AI coding agents** with a plan/act loop and human approval gates
- **Multi-provider LLM support** — Ollama (local), Xenova ONNX (in-process), Cloud APIs (Anthropic, OpenAI)
- **Offline-first** — your code never leaves your machine unless you explicitly use a cloud model
- **MCP-native** — Model Context Protocol support with bundled Agent Reach, UI-UX Pro Max, and Ponytail servers
- **Semantic memory** — Qdrant vector database + BM25 keyword fallback
- **Security tooling** — nmap, Ghidra, Nuclei with safety gates
- **No telemetry, no Microsoft account, no subscription**
