# Kovix Theme Gallery

Tier 3, item 3.2 of the KOVIX Technical Audit roadmap.

This directory contains scaffolding for the bundled theme gallery. Each theme
is a JSON file conforming to the VS Code color theme format.

## Planned Themes (4-6 per roadmap)

1. **Construct Dark** (already exists at `../construct-dark-color-theme.json`)
2. **Construct Light** — TODO: light variant for daytime coding
3. **Cyberpunk** — TODO: neon-on-black, high-contrast syntax colors
4. **Solarized** — TODO: classic Solarized Dark and Light
5. **Gruvbox** — TODO: retro groove color scheme
6. **Nord** — TODO: arctic, north-bluish color palette

## Theme File Format

Each theme is a JSON file with the standard VS Code color theme schema.
See https://code.visualstudio.com/api/references/theme-color for the full
color reference.
